# Recipes App

A REST API application for managing recipes using Node.js, Express.js, and MongoDB.

## Features
- Create Recipe
- Get All Recipes
- Get Recipe By ID
- Update Recipe
- Delete Recipe

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
