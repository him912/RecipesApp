# Recipes App

A REST API application for managing recipes using Node.js, Express.js, and MongoDB.

## Features
- Create Recipe
- Get All Recipes
- Get Recipe By ID
- Update Recipe
- Delete Recipe

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose

🌐 API Base URL
http://localhost:3000/api/recipes

📮 API Endpoints
Method	Endpoint	Description
POST	/api/recipes	Create Recipe
GET	/api/recipes	Get All Recipes
GET	/api/recipes/	Get Recipe By ID
PUT	/api/recipes/	Update Recipe
DELETE	/api/recipes/	Delete Recipe
